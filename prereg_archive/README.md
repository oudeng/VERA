# Prospective-specification evidence bundle

Rule documents (verbatim), their ORIGINAL commit hashes, the
zero-artifact attestation texts from the commit bodies, a
manifest, and SHA-256 checksums. The original development
history contains restricted data and is retained privately;
this directory is the hash-stable evidence layer, and commit
hashes cited in the paper refer to it.

A commit hash fixes this bundle's content exactly, but a
hosting account is not an archive: the history can be
replaced by whoever controls it. No independent
no-later-than anchor is claimed for it. An independent
archival deposit is intended and will be cited when it
completes.
