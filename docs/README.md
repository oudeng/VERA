# docs/

This directory carries the adjudicated configuration register
(`adjudications.md`, asserted by `tests/test_adjudications.py`) and the
corrections ledger (`corrections_ledger.md`) that the Online Resource's
ledger ids point to. The prospectively specified decision-rule
documents referenced throughout the code as `docs/T*.md` live in
`prereg_archive/` together with their original commit evidence.
